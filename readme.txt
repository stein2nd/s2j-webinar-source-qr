Source tracking registration URLs and QR maintenance for GatherPress events (companion to S2J Webinar).

== Description ==

Maintains per-event source tracking URLs and QR PNG documents in event meta. Requires GatherPress for event editing and S2J Webinar for source definitions and provider import.

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/` or install the distribution zip.
2. Run `npm run build:production` (or use a pre-built zip) so `dist/` assets exist.
3. Activate through the Plugins screen.
4. Activate GatherPress and S2J Webinar when using the full maintenance UI.
